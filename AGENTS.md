# Project Rules

## 1. Commits — suggest only, never commit
- NEVER run `git commit`, `git add`, or `git push`. The user commits themselves.
- After every change, write a commit message for the changed/staged files:
  - a single-line title (with conventional-commit prefix required),
  - then at most **5 bullet points** describing the changes.
- Present it as a paste-ready block; the user runs plain `git commit` and pastes it.
